GLASSY IPTV PLAYER

Files:
- index.html
- styles.css
- app.js

Features:
- M3U/M3U8 playlist URL import
- Direct stream URL support
- Local playlist import
- Automatic channel names/logos/groups
- Per-channel delete button
- Search
- Online/Offline/Checking indicator
- Selected channel blue glow and pop animation
- HLS.js and DASH.js playback
- Adaptive quality and 144p/240p/360p/720p/1080p when supplied by the stream
- Data Saver mode

For best browser compatibility, serve the folder through a local web server.
Example: python -m http.server 8080
Then open http://localhost:8080

CORS restrictions may prevent some remote IPTV sources from loading in a browser.
Use only streams you are authorized to access.
